# Professional Static Website

A modern, responsive static website built with HTML, CSS, and JavaScript. Optimized for performance, SEO, and accessibility.

## 🚀 Features

- **Responsive Design**: Mobile-first approach that works on all devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **SEO Optimized**: Proper meta tags, semantic HTML, and structured data
- **Performance Optimized**: Lazy loading, efficient CSS/JS, and optimized assets
- **Accessibility**: WCAG compliant with keyboard navigation and screen reader support
- **Interactive Forms**: Contact form with validation and user feedback
- **Cross-browser Compatible**: Works on all modern browsers

## 📁 Project Structure

```
static-website-example/
├── index.html              # Home page
├── about.html               # About page
├── services.html            # Services page
├── contact.html             # Contact page
├── css/
│   └── styles.css          # Main stylesheet
├── js/
│   └── script.js           # Main JavaScript file
├── assets/
│   ├── logo.svg            # Company logo
│   └── images/             # Image assets
└── README.md               # This file
```

## 🛠️ Technologies Used

- **HTML5**: Semantic markup with modern standards
- **CSS3**: Modern CSS with custom properties, grid, and flexbox
- **JavaScript (ES6+)**: Modern JavaScript with classes and modules
- **Google Fonts**: Inter font family for typography
- **SVG Icons**: Scalable vector graphics for crisp icons

## 🎨 Design System

### Colors
- Primary: `#2563eb` (Blue)
- Secondary: `#64748b` (Slate)
- Accent: `#f59e0b` (Amber)
- Success: `#10b981` (Emerald)
- Error: `#ef4444` (Red)

### Typography
- Font Family: Inter (Google Fonts)
- Base Font Size: 16px
- Line Height: 1.6

### Spacing
- Based on 0.25rem (4px) scale
- Consistent spacing throughout the design

## 🚀 Getting Started

1. **Clone or Download** this repository
2. **Open** `index.html` in your web browser
3. **Customize** the content for your company:
   - Update company name and branding
   - Replace placeholder images
   - Modify contact information
   - Customize services and content

## 📱 Responsive Breakpoints

- **Mobile**: < 480px
- **Tablet**: 480px - 768px
- **Desktop**: 768px - 1024px
- **Large Desktop**: > 1024px

## 🔧 Customization

### Updating Company Information

1. **Company Name**: Search for "YourCompany" and replace with your company name
2. **Logo**: Replace `assets/logo.svg` with your company logo
3. **Contact Info**: Update contact details in all pages
4. **Colors**: Modify CSS custom properties in `styles.css`
5. **Images**: Replace placeholder images in the `assets` folder

### Adding Content

- **Services**: Edit `services.html` to add/modify services
- **Team Members**: Update the team section in `about.html`
- **Testimonials**: Modify testimonials in `services.html`

## 🌐 Deployment

### GitHub Pages
1. Push your code to a GitHub repository
2. Go to repository Settings > Pages
3. Select source branch (usually `main`)
4. Your site will be available at `https://username.github.io/repository-name`

### Other Hosting Options
- **Netlify**: Drag and drop deployment
- **Vercel**: Git-based deployment
- **Traditional Web Hosting**: Upload files via FTP
